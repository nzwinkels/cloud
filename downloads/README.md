# Windows-testversie

Download [SnowboardLab.exe](https://github.com/nzwinkels/cloud/raw/refs/heads/snowboard-prototype/downloads/SnowboardLab.exe)
en dubbelklik op het bestand. Als GitHub eerst de bestandsweergave opent,
gebruik **Download raw file** (het downloadpijltje rechtsboven).

Deze testversie is voor Windows 10/11 op een 64-bit x86-pc. De speldata
zitten in de executable; Godot installeren of een project importeren is
niet nodig. Er zijn geen losse PCK- of DLL-bestanden nodig.

Controller: LB = hielkant, RB = teenkant, linker stick = lichaamsrotatie,
rechter stick omhoog/omlaag = gewicht voor/achter. A = opnieuw,
Y = regular/goofy, Start = pauze. Toetsenbord: Q/E, A/D, W/S, R, G, Esc.

Gebouwd met de officiële Godot 4.6.3 Windows-release-template. Het
template-archief is gecontroleerd met de officiële SHA-512-checksum.
De ingebouwde speldata zijn buiten de ontwikkelmap getest met de Godot
release-runtime op Linux. Windows-uitvoering en het controllergevoel
moeten nog op een Windows-pc worden getest.

De SHA-256 van het testbestand staat in `SHA256SUMS.txt`.
